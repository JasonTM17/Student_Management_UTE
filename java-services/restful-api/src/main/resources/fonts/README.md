# Registration PDF font

`NotoSans-Vietnamese-subset.ttf.b64` is a static 400-weight subset generated
from Google Fonts' `NotoSans[wdth,wght].ttf`. It contains printable ASCII,
Latin/Vietnamese glyphs and the punctuation used by registration slips. The
original font is licensed under the SIL Open Font License in `OFL.txt`.

Source: `https://github.com/google/fonts/tree/main/ofl/notosans`
