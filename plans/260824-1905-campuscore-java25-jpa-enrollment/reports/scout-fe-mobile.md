# FE/mobile scout evidence

Source: read-only scout agents on the pre-execution dirty boundary. This is
planning evidence, not a candidate PASS.

- Web registration currently behaves as a section browser: it does not yet
  enforce server windows/cohort/prerequisites/credit/conflict semantics in the
  UI, and it needs responsive state/reconciliation work.
- Mobile currently lacks the round/semester/search/filter/idempotency/drop/PDF
  parity surface and must share the canonical API contract.
- Assistant UI/client files are dirty/untracked and must be imported/reviewed
  explicitly; browser/device runtime proof remains a later gate.
