# Phase 02 — FE audit and design specification

Audit every public/auth/student/lecturer/admin/assistant route and state at 390, 768, 1024 and 1440px in Vietnamese/English and light/dark modes. Record hierarchy, typography, spacing, responsive, accessibility, copy and state defects with before/after screenshots. Approve the hybrid editorial system: Vietnamese-capable Noto Serif display type for public storytelling, Be Vietnam Pro for all product controls/content, semantic tokens, 4/8px rhythm, 44px touch targets, WCAG AA contrast, visible focus and reduced motion.

Exit criterion: design specialist signs the route matrix and defect ledger; no implementation begins against an unowned or ambiguous route.
